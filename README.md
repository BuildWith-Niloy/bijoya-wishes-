# Aditya greeting page

Upload `index.html`, `style.css`, and `script.js` to the root of your new GitHub Pages repository.

- Default greeting: `Dear,`
- Personal greeting: append `?to=Name` to the URL, e.g. `?to=Niki`
- The Instagram handle opens `https://www.instagram.com/____.dag.____/` in a new tab.
